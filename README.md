Entry for [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/competitions/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) on make.fun.

`main.py` writes one line of deliberately terrible AI advice — a backup tip
that sounds helpful, tidy and confident, and is exactly the sort of thing a
reader could plausibly follow and then regret — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The program is deterministic: every run writes the same bytes. The entry is
one line, 118 characters, inside the competition's 1–140 character gate.
